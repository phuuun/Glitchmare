# Glitchmare

A 2D pixel-art platformer: collect puzzle pieces to beat the ghosts.

**Work in progress.** This branch is the original Unity version and it doesn't currently run. The
game is being remade from scratch in Godot, starting on the
[`godot-migration`](../../tree/godot-migration) branch.
